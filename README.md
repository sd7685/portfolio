# Sunil Dalal — Portfolio

A responsive single-page portfolio prototype built from the information in the supplied resume.

## Included
- index.html — page structure/content
- styles.css — responsive visual design
- script.js — scroll reveal, mobile navigation, cursor glow, dynamic year

## Important
The supplied resume does not contain actual project names, screenshots, URLs, client details, or project outcomes. The Work section therefore uses clearly marked placeholders rather than invented portfolio claims.

## Next customization
Replace the three project cards with real work:
- project screenshot
- project name
- role
- technologies
- short problem/solution/outcome
- live URL or case-study URL

## Local preview
Open `index.html` in a modern browser.

## Squarespace
This design can be recreated in Squarespace using sections, text blocks, image blocks, buttons and code blocks. The CSS/JS can also serve as a visual reference for a custom implementation.
